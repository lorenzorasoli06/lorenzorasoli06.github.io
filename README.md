## 🚀 Pubblicazione su GitHub Pages (Gratuito al 100%)

1. Crea un nuovo repository su GitHub (es. `lorenzo-apnea` o `lorenzorasoli`).
2. Carica i file di questa cartella (`index.html` e la cartella `assets`).
3. Nelle impostazioni del repository (**Settings > Pages**), seleziona come sorgente il branch `main` e la cartella `/ (root)`.
4. Il sito sarà online all'istante su `https://tuo-username.github.io/lorenzo-apnea/`.
5. Per collegare il dominio personalizzato (es. `lorenzorasoli.it`), basterà inserirlo nella casella *Custom domain* di GitHub Pages e impostare i record DNS (CNAME/A) presso il tuo registrar di fiducia (es. Cloudflare, Namecheap o OVH).
